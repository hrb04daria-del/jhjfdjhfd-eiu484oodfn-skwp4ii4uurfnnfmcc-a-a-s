# Хроники Люмьера: запуск за 10 шагов (бесплатно, без банковской карты)

**Схема:** сайт лежит на GitHub Pages, вход и данные хранятся в Firebase (тариф Spark). Ноутбук не нужен: всё работает в облаке, база данных не «засыпает» при неделе без заходов.

## Единая система наград (одна формула вместо двух таблиц)
- Активность: **минуты × 100 × коэффициент**. Институт ×1, Французский ×1,2, Саморазвитие ×1, Работа ×0,25. Долги и «хвосты» дополнительно ×1,5.
- Крупные события (зачёт 15 000, экзамен 40 000, модули, проект, сертификаты) идут фиксированной суммой из списка в калькуляторе.
- Проценты складываются: серия (3 дня +10%, 7 +20%, 14 +30%), «сам придумал» +20%, оценка (хорошо +15%, отлично +30%, только для зачёта и экзамена), Лупа Архивариуса +5%.
- Потом плоские бонусы: газета +1 500, сверхурочные +5 000, день отдыха +3 000, «Три корзины» +30 000.
- Мягкий предел: сверх 45 000 Кристаллов за день награда ×0,5 (сертификаты и «Три корзины» не считаются).
- **ОВ всегда 10% от Кристаллов.** Все числа лежат в `js/data.js`, раздел ECON.
- Отличие от старых таблиц: смена 8 часов теперь 12 000 (было 10 000). Всё остальное совпало с таблицей.

## Шаги
1. Создайте аккаунт на github.com и на firebase.google.com (вход через Google подойдёт).
2. Firebase → **Create a project** → название `lumiere`, Google Analytics выключить.
3. В проекте: **Build → Authentication → Get started → Email/Password → Enable → Save**. Затем вкладка **Settings → User actions**: снимите галочку **Enable create (sign-up)**. Так никто чужой не создаст аккаунт.
4. **Authentication → Users → Add user**: создайте два аккаунта. Почта у обоих вида `логин@lumiere.game` (например `friend@lumiere.game` и `curator@lumiere.game`) и пароль. Вводить на сайте нужно только часть до `@`. Скопируйте **User UID** каждого.
5. **Build → Firestore Database → Create database** → Production mode → любой регион ближе к вам. Вкладка **Rules** → вставьте всё из файла `firestore.rules` → **Publish**.
6. **Project settings (шестерёнка) → Your apps → значок `</>`** → зарегистрируйте веб-приложение → скопируйте `apiKey`, `authDomain`, `projectId`, `appId` в файл `js/config.js`.
7. В Firestore → **Start collection** → название `roles`. Два документа:
   - Document ID = UID игрока; поле `role` (string) = `player`.
   - Document ID = UID куратора; поля `role` = `curator` и `panel` = `./kp-7f3a91.js`.
8. GitHub → **New repository** (публичный, бесплатный Pages требует этого) → **uploading an existing file** → перетащите всё содержимое папки (`index.html`, папка `js`, остальное). **Settings → Pages → Branch: main, / (root) → Save**. Через пару минут появится ссылка вида `https://имя.github.io/репозиторий/`.
9. Firebase → **Authentication → Settings → Authorized domains → Add domain** → `имя.github.io`.
10. Проверка: зайдите под игроком (видны крутки, сюжет, никаких следов панели куратора), затем под куратором в другом браузере. Начислите 10 000 в калькуляторе и проверьте, что у игрока появились Кристаллы.

## Безопасность: честно
- Правила базы запрещают игроку увеличивать Кристаллы и ОВ (только тратить или получить точную награду неиспользованного промокода). Начисления, промокоды, настройки, Гараж может менять только куратор. Чужие аккаунты не создаются (шаг 3), а без записи в `roles` доступа к данным нет.
- **Слабое место:** крутки считаются в браузере игрока (платных серверных функций без карты нет). Технически подкованный игрок, открыв консоль, может подделать результат крутки или выбор в сюжете, но не может добавить себе валюту. Для личной игры двух людей это разумный компромисс.
- **Невидимость панели куратора:** игрок не видит ни кнопок, ни ссылок, ни упоминаний, и код панели ему не загружается: путь к файлу хранится в базе и отдаётся только куратору. Полностью скрыть сам файл нельзя: он лежит в публичном репозитории под неочевидным именем `kp-7f3a91.js`. Угадать это имя почти нереально, а без аккаунта куратора файл бесполезен. Для надёжности переименуйте файл и поменяйте поле `panel` в `roles`.

## Лимиты (Spark, проверяйте в консоли актуальные цифры)
Firestore: около 50 000 чтений и 20 000 записей в день, 1 ГБ. Для двух человек этого с огромным запасом. При превышении база до следующего дня перестанет принимать запросы (платить не придётся, карта не привязана).

## Правки и копии
- Правки: меняйте файлы в репозитории GitHub (значок карандаша → **Commit changes**), сайт обновится сам.
- Копия: в панели куратора внизу **Скачать копию** (делайте раз в неделю). Восстановление: **Загрузить копию**.
- Если что-то сломалось: откройте сайт, нажмите F12 → Console и пришлите мне красные строки; проверьте `js/config.js`, домен в шаге 9 и документы `roles`.

## Допущения, которые я сделал (поменять можно в `js/data.js`)
- Дубли героя после 3 Воспоминаний дают 10 Осколков. «Чистый лист» = +20 000 💎 и +2 000 ОВ. Цены сделки (1 000) и штурма (2 000), «выиграть время» в Главе 4 (1 500) придуманы мной.
- Судьба героя записывается в сюжете независимо от коллекции. Погибшие, но не выпавшие герои попадут в Мемориал сразу после выпадения.
- Серию дней куратор выбирает в калькуляторе вручную.

## Картинки
Папка `images` лежит рядом с `index.html`. Файлы называются по латинскому коду героя, строчными буквами.
- `images/heroes/` портреты: selest, kassian, adrienne, henri, lucien, noel, isolde, damien, mirey, bastien, juliette, auguste, tristan, madeleine, raphael, emile (например `henri.webp`).
- `images/items/` звери и предметы: echo, sova, senator, kassandra, miraj, grosh, iskra, nozhik, fermata, bint, blik, precedent, vecherniy, pirat, palitra, midnight, confession, regent, verdict, tuz, balance, resonance, twins, grandmaitre, sumka, otmychki, protez, pero, kompas, kist, lupa, chasy, perstn, return, sight, delay, lantern.
- `images/scenes/` кат-сцены: любое имя, затем в `js/data.js` в нужную сцену добавляется поле `img:'имя.webp'`.
Формат по умолчанию `.webp`. Если у вас `.png` или `.jpg`, поменяйте слово в строке `IMG_EXT` в начале раздела «КАРТИНКИ» в `js/data.js`. Лучше всего вертикальные 3:4 (например 600×800), до 300 КБ каждая. Если файла нет, карточка просто показывается без картинки.
